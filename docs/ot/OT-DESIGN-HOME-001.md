## Objetivo

Definir el estándar visual que todas las futuras OTs de Home deben implementar. Esta OT **no modifica componentes, CSS ni lógica**.

## Entregables

- Especificación de dirección de arte v2
- Narrativa emocional por bloque
- Sistema visual (fotografía, tipografía, color, cards)
- Reglas explícitas (prohibido / permitido)
- Metodología Diseño → Implementación → Lock
- Actualización del registro UI con roadmap v2

## Alcance

| Incluye | Excluye |

| Filosofía y narrativa | Código de componentes |
| Referencias visuales | Cambios CMS / APIs |
| Criterios por sección | Modificar Hero / Footer LOCKED |
| Flujo de aprobación | Implementación directa |
