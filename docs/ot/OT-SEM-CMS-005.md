| Atributo | Valor |

## Objetivo

Centralizar activos multimedia institucionales en una biblioteca reutilizable, con metadatos en MongoDB y binarios en almacenamiento de objetos.

## Alcance

Media Library admin, API REST, MediaPicker, integración con Configuration Hub y Page Builder (bloque Hero). Content Engine y sincronización completa de `usage` quedan como extensión.
