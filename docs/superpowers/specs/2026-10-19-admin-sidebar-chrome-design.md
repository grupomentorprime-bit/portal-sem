# Admin sidebar chrome (opción B) — Design

Fecha: 2026-10-19  
Estado: aprobado  
Complementa: [admin-sidebar-flat](./2026-10-19-admin-sidebar-flat-design.md)

## Objetivo

Acercar el chrome del sidebar a la referencia visual: marca, íconos y pie (Espacio + aceleración), sin inventar billing ni onboarding real.

## Comportamiento

### Cabecera
- Solo Growth OS (isotipo tipo barras + nombre).
- Sin tarjeta «Espacio activo» arriba.

### Navegación
- Lista plana ya aprobada; íconos alineados a la referencia (casa, personas, megáfono, rayo, barras, monitor, edificio, equipo, engranaje).

### Pie
1. **Espacio** — corona, nombre del Espacio, subtítulo «Plan Pro», chevron → `/admin/settings/team` (o Ajustes si no hay Equipo).
2. **Acelerar** — maqueta fija: 70 %, copy «Acelera tu crecimiento», CTA «Continuar» → `/admin`.

### Fuera de alcance
- Planes reales, % calculado, cambios del área de contenido.
