| Atributo | Valor |
| --- | --- |
| Estado | Aprobado |
| Fecha | 2026-09-04 |

| Alcance | Solo contrato de producto — **sin implementación** |

---

## Contexto

SaaS Foundation V1 está cerrada: T001 SEM y T002 ADL conviven en el mismo core (ADR-008, SAAS-001→009). El runtime ya es multi-tenant. El **producto** todavía se presenta como Portal SEM / AprendeHoy Learning OS.

Eso bloquea vender o operar Growth OS: el chrome, los fallbacks y los docs de entrada siguen hablando del primer cliente o de un sistema académico que no es este repo.

ADR-008 dejó fuera, a propósito: CRM, Growth Core, automatizaciones y UX nueva. Este ADR cierra el contrato de **quién es el producto** antes de tocar chrome, correo o docs.

No se reabre SAAS-001→009 salvo regresión demostrada.

---

## Decisión

Este repositorio es **Growth OS**: la plataforma. Educación es una **vertical**. SEM y ADL son **clientes** (Espacios). **Aprende Hoy** es el sistema académico, otro producto, con handoff opt-in.

Productization V1 hace que Growth OS se vea y se nombre como producto, sin lógica por cliente y sin mezclar Growth Core.

## 2. Decisiones nuevas (contrato mínimo)

### D1 — Growth OS es el producto

| Capa | Nombre |
| --- | --- |
| Producto | **Growth OS** |
| Código / repo histórico | `portal-sem` (no se renombra en Productization V1) |
| Cliente en un host | **Espacio** + **Sitio** (ADR-008) |

Growth OS opera organizaciones: identidad, Espacios, CMS, media, formularios, flujos, eventos, portal público. No es el seminario. No es el LMS.

Educación (portales institucionales, convocatorias, admisión de interesados) es la **primera vertical**, no el nombre del producto.

### D2 — Clientes ≠ producto ≠ vertical

| Nombre | Rol |
| --- | --- |
| **Growth OS** | Producto (esta plataforma) |
| **Vertical educación** | Capacidad de dominio: sitio institucional, programas editoriales, formularios, jornadas |
| **SEM (T001)** | Cliente; pack de datos `seminario-ipn` |
| **ADL (T002)** | Cliente; Espacio limpio sobre el mismo core |
| **Aprende Hoy** | Sistema académico (matrícula, campus, evaluación). Fuera de este producto |

Prohibido: `if (tenant === "adl")` / `if (cliente === …)` como identidad de producto. `isSemTenant` sigue siendo el gate del **pack SEM** (SAAS-007), no una marca de plataforma.

### D3 — Aprende Hoy no se reescribe aquí

- Este repo **no** almacena alumnos, matrículas, pagos, expedientes ni campus.
- El adapter `AprendeHoyAdmissionAdapter` permanece opt-in.
- Copy de T001 que mencione Aprende Hoy es **dato del cliente**, no chrome de Growth OS.
- Roadmaps que traten este repo como «Learning OS» quedan históricos hasta la OT de docs de entrada.

### D4 — Lenguaje visible vs lenguaje de código

| Persona ve | Código / DB |
| --- | --- |
| Espacio | `Tenant` / `tenantId` |
| Sitio | `Site` / `siteId` |
| Cuenta | `identity_users` |
| Invitación | `identity_invitations` |
| Inicio | `/admin` |
| Growth OS | producto (docs, créditos de plataforma) |

**No se muestra en UI:** `tenant`, `tenantId`, `T001`, `SaaS`, `Learning OS`, `Portal SEM` como nombre de producto, `CMS del SEM`.

Palabras humanas para chrome de plataforma: Espacio, Sitio, cuenta, invitación, entrar, salir.

### D5 — Fallback de plataforma (sin inventar un cliente)

Cuando el Site no tiene nombre:

| Superficie | Fallback |
| --- | --- |
| Admin / login | Hablar del **Espacio**, no de SEM ni de un LMS |
| Portal público | Metadata/branding del Site; si falta, genérico — **nunca** SEM |
| Correo | Nombre del Site/Espacio; si falta, nombre de producto **Growth OS** |
| Créditos de plataforma | Growth OS (no «Learning OS», no «Portal SEM») |

`PLATFORM_DISPLAY_NAME` deja de ser un eufemismo de SEM. Hoy vale `"Portal"`: insuficiente como producto y todavía no es Growth OS. Lo cambia la primera OT de implementación, no este ADR.

Datos de T001 (nombre Seminario, IPN, Talca, generaciones) **no se tocan**: siguen en `site_config` / contenido SEM.

### D6 — Productization ≠ Growth Core

| Frente | Qué es | Cuándo |
| --- | --- | --- |
| **Productization** | Que Growth OS se nombre, se vea y se opere como producto: chrome, correo, defaults, docs de entrada | Ahora (V1) |
| **Growth Core** | Núcleo Persona → Origen → Oportunidad → Actividad → Próxima acción (no recorridos/planes) | **Después** de Productization V1. Contrato: [ADR-010](./ADR-010.md) |

Productization V1 **no** crea CRM, no crea planes de cobro, no crea onboarding self-serve completo, no toca producción.

### D7 — Chrome de producto vs pack de cliente

| Capa | Dueño | Ejemplo |
| --- | --- | --- |
| Chrome / defaults de plataforma | Growth OS | Login, empty states de admin, `EMAIL_FROM` de proceso, placeholders de créditos |
| Pack T001 | Datos SEM | Home, menús, admisión, convocatorias, logos IPN |
| Pack T002 | Datos ADL | Identidad ADL; sin pack SEM |

Cambiar chrome no autoriza a reabrir migraciones SAAS ni a extraer otra vez seeds SEM.

## 3. Mapa de producto

```text
Growth OS                          ← este repositorio (producto)
├── Platform Core                  ← Identity, Tenant, CMS, Media, Workflow, Events
├── Productization                 ← este frente (identidad, lenguaje, chrome)
├── Growth Core                    ← contrato ADR-010; no implementado
└── Vertical educación
      ├── Cliente SEM (T001)
      ├── Cliente ADL (T002)
      └── Handoff opt-in → Aprende Hoy (sistema académico, otro producto)
```

## 4. Hallazgos que Productization V1 debe cerrar (no en este ADR)

Inventario mínimo, ya visible en runtime — **implementación en OTs posteriores**:

| Superficie | Hoy | Destino |
| --- | --- | --- |
| Login admin | «Acceso institucional al CMS del SEM» | Texto de Espacio, sin cliente |
| `PLATFORM_DISPLAY_NAME` | `"Portal"` | Nombre de producto / fallback D5 |
| Defaults de créditos | «Learning OS» / placeholders AprendeHoy | Crédito Growth OS o vacío |
| `EMAIL_FROM` de proceso | genérico / legado «Portal SEM» en scripts | Identidad del Site; env solo como transporte |
| Docs de entrada | README / Handbook = Portal SEM / Learning OS | Growth OS; SEM como T001 |
| Catálogos internos | «AprendeHoy» en design system / AEK | Renombre en OT de docs/chrome interno; sin rediseño |

Fuera de V1: alta self-serve de Espacio, DNS/TLS, entitlements, Growth Core, reescritura masiva de OTs históricas.

## Alternativas descartadas

| Alternativa | Motivo |
| --- | --- |
| Seguir llamando al producto «Portal SEM» | Confunde cliente y plataforma; T002 ya existe |
| Llamar al producto «AprendeHoy Learning OS» | Ese nombre es el sistema académico; viola el corte portal ≠ ERP |
| Empezar Growth Core (CRM) ahora | El chrome todavía dice SEM; no hay contrato de producto |
| Renombrar el repo / package en V1 | Cosmético; no desbloquea clientes; se puede hacer después |
| Reescritura masiva de docs históricas | Ruido; las OT viejas quedan como historia |
