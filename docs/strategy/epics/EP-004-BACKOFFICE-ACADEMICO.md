# EP-004 — Backoffice Académico

| Atributo | Valor |
| --- | --- |
| Código | EP-004 |
| Estado | ⚪ Pendiente |
| Dependencia | EP-000 ✅ · CMS alineado ✅ |

---

## Objetivo

Potenciar el **CMS ya alineado con el Experience Kit** para la operación académica e institucional: contenidos, landings, multimedia y SEO sin duplicar el panel administrativo.

---

## Alcance

| Área | Descripción |
| --- | --- |
| Gestión académica | Programas, períodos, catálogos (vía Content Engine) |
| Docentes | Perfiles, publicación en portal |
| Noticias y avisos | Flujo editorial |
| Biblioteca | Catálogo y metadatos |
| Landing pages | Page Builder + bloques premium |
| Multimedia | Media Manager (Asset Engine) |
| SEO | Meta, JSON-LD, sitemap por tenant |
| Configuración institucional | Hub existente extendido |
